This diagnostic captures original h function code-object identities after bounded
held-source admission and before actors. The exact h58 bytes and generated finite
require/direct-raise site table are pinned. It walks at most32 traceback nodes and
reads only tb_next, frame.f_code and tb_lineno. It reads no frame locals/globals,
filenames, exception strings, arguments or private command output. A guard code is
emitted only when the original AdmissionError class and terminal original require
or direct-raise site correlate with a finite original function/site. Unknown,
foreign, same-line cloned code and excessive traces remain unclassified. No
exception attributes supplied by callers become evidence.

the old scanner-start marker covered both Scanner.start and this constructor.

and captured, so a bridge refusal cannot be presumed an h scanner-process failure.

qualified code paths are structurally matched including bytecode, typed constants,
line/exceptiontables/signature fields but excludingfilename. Original functions
must reference the actual admitted module namespace by identity, without reading
its contents. Foreignsame-first-line bodies or foreign namespaces are refused.
